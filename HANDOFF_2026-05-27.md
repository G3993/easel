## Known issues / next steps

1. **Combo container bg matching** — pushed `FrameBg = K` around `BeginCombo`, but if any other widget type still reads as a "lighter container" (sections, sliders, etc.), find that color in `applyTheme` and dim it. PropertyPanel slider tracks use `FrameBg` so making it pure black hides the track; consider `IM_COL32(8, 8, 8, 255)` for slight contrast.
2. **`Application.cpp` AVFoundation link error** — `test_audio_analyzer` target fails to link (`_AVMediaTypeAudio`, `_OBJC_CLASS_$_AVCaptureDevice`). Pre-existing, not from this session. Add `"-framework AVFoundation"` to `test_audio_analyzer`'s link libs in `CMakeLists.txt`.
3. **Two ShaderClaw3 copies on disk** — `/Users/lu/ShaderClaw3/` is the one Easel actually reads (per `Application.cpp:436`). `/Users/lu/easel/external/ShaderClaw3/` is a stale older copy from May 5 and should either be deleted or sync'd from the live tree.
4. **The pill-bar architecture** rendered at host level + `NoTabBar` + sticky `VisibleWindow` is a workaround for ImGui's docking. If you want a cleaner build, the proper refactor is: drop ImGui docking for the right dock entirely, render each panel as a plain `ImGui::Begin(...)` window whose visibility is toggled by `m_currentRightPanel`. Removes all the dock contortions.
