## What shipped this session

### Easel C++ (commit 8c88c97 on fork/master)
1. **PropertyPanel pinned source-nav** — 6-icon quick-bar (Properties / Shader /
   Mic / Cam / Win / Mapping) pinned at top, sticky during scroll (content wrapped
   in `##propContent` child). `UIManager::renderRightDockNavBar`.
2. **Killed the dead Sources TabBar** — the "..." ellipsis strip. `focusSourcesTab`/
   `activeSourcesTab` now use an explicit `static SourceTab s_activeSubTab` (UIManager.cpp);
   Application.cpp Sources panel branches on `m_ui.activeSourcesTab()` instead of
   `BeginTabItem`. Spout block gated `false &&`.
3. **Mic works** — `AudioAnalyzer_mac.mm` now does an explicit `AVMediaTypeAudio`
   TCC request (CoreAudio HAL doesn't auto-prompt). Application auto-boosts input
   gain to 4.0× on mic-device select (mic is far quieter than loopback). Codesign
   uses stable "Easel Dev" identity so the grant persists across rebuilds.
4. **Fluid image-inject** — `FluidSource` `FS_INJECT` pass adds a bound layer's
   texture into the dye field each frame (smeared by velocity). `m_image` slot +
   `applyImageInject()` + `imageIntensity` audio-binding + save/load. PropertyPanel
   "Image Inject" section: enable + layer picker + inline **+Image/+Video/+Shader**
   buttons (LayerPanel::postCreateBindFluidImage auto-binds the new layer).
5. **NDI output async readback** — `NDIOutput` now uses double-buffered PBOs;
   removed the per-frame `glFinish()` that stalled the whole render loop and made
   received NDI choppy.
6. **Fast fullscreen** — `toggleEditorFullscreen` = borderless windowed (no
   display-capture freeze) + `PlatformMac.mm` auto-hides menu bar/Dock.
7. **Double-click layer hide** — root cause was Application.cpp `[LayerThumb]`
   handler toggling `layer->visible` only; `Timeline.cpp:588` reset it next frame.
   Fixed to toggle `userHidden` then set `visible`. Also removed LayerPanel's
   single-click-thumb-toggle that was fighting it.
8. **macOS shader hot-reload** — `ShaderClawBridge::update` had a Windows-only
   `pollFileChanges`; added a 250ms mtime-poll fallback so `.fs` edits reload live
   on Mac. (This is why earlier shader edits "didn't work" until relaunch.)
