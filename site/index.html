34 studio shaders. The gallery and both SHOW decks open on it. Copy it, regroup it, or build your own groups.

Tools

SHOW mixer with A/B decks, projection mapping and masks, audio and MIDI binding, NDI in/out, screen and window capture, timeline.

ShaderClaw

Shader library

github.com/G3993/ShaderClaw3

Easel already carries a copy. To get new shaders as they're published, or to add your own, keep a live copy at ~/ShaderClaw3. The Mac installer sets this up. Easel loads it automatically on launch.

git clone --depth 1 https://github.com/G3993/ShaderClaw3.git ~/ShaderClaw3

Update later with git -C ~/ShaderClaw3 pull. On Windows the bundled copy is used; to use a live one, rename the ShaderClaw3 folder next to Easel.exe and clone to %USERPROFILE%\ShaderClaw3.

First run

macOS

  1. Open Easel. When macOS asks, allow Screen & System Audio Recording (for audio reactivity and window capture), plus Microphone and Camera if you use them.
  2. If you missed a prompt: System Settings → Privacy & Security → Screen & System Audio Recording → turn on Easel, then reopen it.
  3. Open the Gallery to browse the Studio Pack, then send a shader to SHOW.

Windows

  1. Run Easel from the Desktop shortcut, or run Easel.exe in the unzipped folder.
  2. Audio reactivity follows your default output device. Choose a microphone in the Audio tab.
  3. Optional: install the NDI Runtime from ndi.video for NDI send and receive.

Good to know

  • MIDI starts off. Click the MIDI pill to turn it on. Launch Control XL (classic and mk3) is mapped automatically.
  • Your projects, groups and shader settings are stored in ~/.easel. Updating Easel keeps them.
  • Builds are not notarized by Apple or signed for Windows, so expect the first-launch warnings described above.
